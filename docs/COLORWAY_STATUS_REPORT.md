### 3. Storefront UI/UX Handling of Provisional Slots
* **Variant Chip Indicator**: `[Color] (Dev)` chip tag clearly denotes provisional status.
* **Dynamic Concept Canvas**: Replaces the product gallery with a luxury editorial card matching the exact hex tone, stating `COLORWAY IN DEVELOPMENT / AWAITING APPROVAL`.
* **Zero Image Cross-Contamination**: Does not display Black hoodie photos when Cream or Maroon is clicked.
* **Gated Commerce**:
  - `ADD TO BAG` button displays: `COLORWAY IN DEVELOPMENT · NOT FOR SALE`.
  - Button disabled with `opacity: 0.6; cursor: not-allowed;`.
  - WhatsApp CTA updates to: `💬 INQUIRE ABOUT PRE-RELEASE`.
  - Serverless order API strictly rejects any provisional SKU submitted.
